# Friday's news in one page

This image presents four stories dated Friday, 13 November 2026: peace talks
over Ukraine, the resignation of NVIDIA's chief executive, a Microsoft
service outage, and Storm Charles battering a harbour. Its newspaper front
page brings the scenes together as a compact record of the day.

The program reads the JPEG beside itself, checks its size, signature, frame
dimensions, and end marker, then copies the original bytes to
$MAKEFUN_OUTPUT_DIR/entry.png (or /output/entry.png when that variable is
unset). It creates the destination directory and prints the file path, byte
count, dimensions, and SHA-256 digest.

It also rejects files smaller than 1024 bytes as likely truncated.
